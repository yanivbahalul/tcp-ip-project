# מימוש תקשורת בין שרת ללקוחות באמצעות TCP/IP

פרויקט המדגים תקשורת בין שרת למספר לקוחות באמצעות TCP/IP.

המערכת כוללת ממשק גרפי לשרת וללקוחות, מאפשרת למספר משתמשים להתחבר במקביל, לבחור משתמש מחובר ולשלוח אליו הודעות.

## התקנה

יש להיכנס לתיקיית הפרויקט ולהתקין את הספריות הנדרשות:

```bash
cd prt2
pip install -r requirements.txt
```

במערכות שבהן משתמשים ב־`python3`:

```bash
cd prt2
pip3 install -r requirements.txt
```

## הפעלת השרת

להפעלת השרת:

```bash
cd prt2
python server_gui.py
```

או:

```bash
cd prt2
python3 server_gui.py
```

לאחר פתיחת חלון השרת יש להגדיר:

* **Binding IP Address**
  `0.0.0.0` – מאפשר חיבור ממחשבים אחרים באותה רשת.
  `127.0.0.1` – מאפשר חיבור רק מהמחשב המקומי.

* **Listening Port**
  ברירת המחדל היא:

```text
10000
```

לאחר מכן יש ללחוץ על:

```text
RUN SERVER
```

## הפעלת הלקוח

להפעלת הלקוח:

```bash
cd prt2
python client_gui.py
```

או:

```bash
cd prt2
python3 client_gui.py
```

בחלון ההתחברות יש להזין:

* **Nickname** – שם המשתמש שיוצג למשתמשים האחרים.
* **Server IP** – כתובת ה־IP של המחשב שעליו רץ השרת.
* **Port** – הפורט שעליו השרת מאזין.

כאשר השרת והלקוח רצים על אותו מחשב:

```text
127.0.0.1
```

כאשר השרת רץ על מחשב אחר ברשת המקומית, יש להזין את כתובת ה־IP של מחשב השרת.

לדוגמה:

```text
10.0.0.12
```

פורט ברירת המחדל:

```text
10000
```

לאחר מכן יש ללחוץ על:

```text
LOGIN
```

## שימוש במערכת

1. מפעילים את `server_gui.py`.
2. מגדירים כתובת IP ופורט.
3. לוחצים על `RUN SERVER`.
4. מפעילים את `client_gui.py`.
5. מזינים שם משתמש, כתובת שרת ופורט.
6. לוחצים על `LOGIN`.
7. לאחר ההתחברות תופיע רשימת המשתמשים המחוברים.
8. בוחרים משתמש מהרשימה.
9. כותבים הודעה ולוחצים על `SEND` או על Enter.
10. הודעות נכנסות יוצגו אוטומטית בחלון הצ'אט.

## חיבור בין מחשבים באותה רשת

כדי לאפשר ללקוחות ממחשבים אחרים להתחבר לשרת, יש להגדיר במחשב השרת:

```text
0.0.0.0
```

במחשב הלקוח יש להזין את כתובת ה־IP המקומית של מחשב השרת.

לדוגמה:

```text
10.0.0.12
```

השרת והלקוחות צריכים להשתמש באותו פורט.

ברירת המחדל:

```text
10000
```

## הרצה על אותו מחשב

כאשר השרת והלקוח רצים על אותו מחשב, ניתן להשתמש בכתובת:

```text
127.0.0.1
```

גם השרת וגם הלקוח צריכים להיות מוגדרים לאותו פורט.
