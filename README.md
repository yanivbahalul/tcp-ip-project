# TCP/IP Client-Server Communication

Simple TCP/IP chat system with a GUI.

The server supports multiple clients at the same time.

## Install

```bash
cd prt2
pip install -r requirements.txt
```

## Run Server

```bash
python server_gui.py
```

Use:

```text
IP: 0.0.0.0
Port: 10000
```

Then click `RUN SERVER`.

## Run Client

```bash
python client_gui.py
```

Enter:

```text
Nickname: Your name
Server IP: Server IP address
Port: 10000
```

Then click `LOGIN`.

For local testing, use:

```text
127.0.0.1
```

Choose a connected user and send messages.
